# Paradise Nursery Shopping Application

A responsive React shopping cart application for an online houseplant shop.

## Features
- Nursery landing page with a background image and Get Started button
- About Us section
- Three houseplant categories with six unique products in each category
- Product images, names, descriptions, and prices
- Redux Toolkit cart state and dynamic cart count
- Add-to-cart buttons disabled after adding a product
- Increase/decrease quantities and remove products
- Subtotals and total cart amount
- Checkout message and continue-shopping navigation
- Responsive layout

## Tech stack
React, Vite, Redux Toolkit, React Redux, Lucide React, and CSS.

## Run locally
1. Install Node.js LTS.
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

To check the production build, run `npm run build`.
